# Curated experiment artifacts

Run artifacts are retained here when they should accompany the code. New
unreviewed local runs remain under the ignored `runs/` directory.

- `smoke/`: one-round no-attack plumbing check; not research evidence.
- `exploratory_delta_pilot/`: one-seed five-control pilot; not strictly paired
  because Flower node IDs and client data/RNG assignments varied across
  invocations. See `docs/experiment_protocol.md`.
